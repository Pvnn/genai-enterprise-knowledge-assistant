# Metadata Tagger

**Owner:** P1
**Stage:** 0
**Priority:** 1
**Files:** `backend/app/ingestion/metadata_tagger.py`

## What it does

It takes the raw dictionary chunks generated by the heading-aware chunker and enriches them with essential document-level and system-level metadata (like `tenant_id`, `document_id`, `department`, `doc_type`). Most importantly, it safely casts these dictionaries into fully validated `ChunkDB` Pydantic models before handing them down the pipeline to ensure absolute data integrity.

## Example

**Input:** `[{"text": "Sample text", "section_path": "Heading 1"}]`
**Output:** `[ChunkDB(id=UUID, document_id=UUID, tenant_id=UUID, text="Sample text", section_path="Heading 1", department="HR", ...)]`
